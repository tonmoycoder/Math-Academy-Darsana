## 1. `sitemap.xml`

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9"
        xmlns:image="http://www.google.com/schemas/sitemap-image/1.1">
  <url>
    <loc>https://math-academy-darsana.vercel.app/</loc>
    <lastmod>2026-10-25</lastmod>
    <changefreq>weekly</changefreq>
    <priority>1.0</priority>
    <image:image>
      <image:loc>https://math-academy-darsana.vercel.app/og-1200x630.jpg</image:loc>
      <image:title>ম্যাথ একাডেমি — দর্শনা, চুয়াডাঙ্গা</image:title>
    </image:image>
  </url>
</urlset>
```

**Rules that matter**

- One page → one `<url>`. A single-page site must **not** list `#anchors`; fragments are
  the same URL to Google and create duplicate-URL noise.
- `lastmod` must be a real content-change date. Lie about it and Google ignores the signal.
- `priority` and `changefreq` are *hints Google has publicly said it ignores*; they are kept
  because Bing/Yandex/other engines still read them and the owner asked for them explicitly.
- The `<loc>` must be the **canonical, HTTPS, non-www** URL, byte-identical to
  `<link rel="canonical">`. Build rewrites the host from `SITE_HOST`, so drift is impossible.
- The 404 page is deliberately **absent** from the sitemap.

## 2. `robots.txt`

```txt
# ম্যাথ একাডেমি — দর্শনা, চুয়াডাঙ্গা
User-agent: *
Allow: /
Disallow: /admin/
Allow: /*?fast=

# AI answer engines (GEO / AEO) — explicitly welcomed
User-agent: GPTBot
Allow: /
… (OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-Web, PerplexityBot,
   Google-Extended, Applebot-Extended, Bytespider, CCBot)

Sitemap: https://math-academy-darsana.vercel.app/sitemap.xml
```

**Rules that matter**

- `User-agent: *` / `Allow: /` is the whole requirement; everything else is a bonus.
- The `Sitemap:` line must be an **absolute URL** (relative paths are ignored by everyone).
- `Disallow: /admin/` is defensive: no such folder exists, but if one ever does it will not be
  indexed before someone remembers to block it. Same reasoning for `Allow: /*?fast=`.
- The AI-bot block is the **GEO/AEO** half of the SEO strategy: it lets ChatGPT/Claude/Perplexity
  read the page so the academy can be *cited* in answer engines. Remove those blocks only if the
  owner ever wants to opt out of AI answers.
- No `Crawl-delay` (Google ignores it; it would only slow Bing).
- `robots.txt` must sit at the **domain root** — it cannot live in a subfolder.

## 3. Canonical + CSP inside `<head>`

```html
<link rel="canonical" href="https://math-academy-darsana.vercel.app/">
<link rel="alternate" hreflang="bn-BD" href="https://math-academy-darsana.vercel.app/">
<link rel="alternate" hreflang="x-default" href="https://math-academy-darsana.vercel.app/">

<meta http-equiv="Content-Security-Policy"
      content="default-src 'self'; img-src 'self' data:; style-src 'self' 'unsafe-inline';
               script-src 'self' 'unsafe-inline'; font-src 'self' data:; connect-src 'self';
               object-src 'none'; base-uri 'self'; form-action 'self'">
```

**Why exactly this**

| Directive | Value | Reason |
|---|---|---|
| `default-src` | `'self'` | nothing loads from a third-party origin — there is no CDN, no analytics, no API |
| `img-src` | `'self' data:` | the offline single-file build embeds the photos as data URIs |
| `style-src` / `script-src` | `'self' 'unsafe-inline'` | **required**: `build.py` inlines every style block and every script (GSAP included) |
| `font-src` | `'self' data:` | Bengali subsets are self-hosted; the offline build embeds them |
| `connect-src` | `'self'` | the site makes zero XHR/fetch calls, so every **external** origin stays blocked; `'self'` is kept instead of `'none'` because Lighthouse's robots.txt gatherer performs a same-origin fetch — `'none'` silently drops the SEO audit to 92 |
| `object-src` | `'none'` | kills legacy plugin vectors |
| `base-uri` / `form-action` | `'self'` | blocks `<base>` hijacking and form exfiltration |

**Deliberate departure from the generic brief:** the brief asked to *allow Google Fonts*.
This site **self-hosts** its fonts, so allowing `fonts.googleapis.com` / `fonts.gstatic.com`
would only widen the attack surface for zero benefit. The locked-down version is strictly
better for the security signal (and for LCP).

If a future version ever does load Google Fonts, the minimum change is:

```html
style-src 'self' 'unsafe-inline' https://fonts.googleapis.com;
font-src  'self' data: https://fonts.gstatic.com;
```

**www vs non-www:** the canonical tag prevents duplicate-content scoring, but the *real* fix
is a permanent redirect at the host (`www.` → apex). On Vercel/Netlify/Cloudflare that is a
domain-level setting in their dashboard, not a file.

**Meta vs header:** a `meta` CSP cannot express `frame-ancestors`, and if both a meta policy
and a header policy exist the browser enforces the **intersection** (most restrictive wins).
Here they are identical on purpose, and the header adds `frame-ancestors 'self'`.

## 4. Security headers

### 4.1 `vercel.json` (primary — this project's target)

```json
{ "$schema": "https://openapi.vercel.sh/vercel.json",
  "cleanUrls": true, "trailingSlash": false,
  "headers": [
    { "source": "/assets/(.*)",
      "headers": [{ "key": "Cache-Control", "value": "public, max-age=31536000, immutable" }] },
    { "source": "/404",
      "headers": [{ "key": "Cache-Control", "value": "no-store" },
                  { "key": "X-Robots-Tag", "value": "noindex" }] },
    { "source": "/(.*)", "headers": [
      { "key": "Strict-Transport-Security", "value": "max-age=63072000; includeSubDomains; preload" },
      { "key": "X-Frame-Options",           "value": "SAMEORIGIN" },
      { "key": "X-Content-Type-Options",    "value": "nosniff" },
      { "key": "Referrer-Policy",           "value": "strict-origin-when-cross-origin" },
      { "key": "Permissions-Policy",        "value": "camera=(), microphone=(), geolocation=(), payment=(), usb=()" },
      { "key": "Cross-Origin-Opener-Policy","value": "same-origin" },
      { "key": "Content-Security-Policy",   "value": "default-src 'self'; img-src 'self' data:; style-src 'self' 'unsafe-inline'; script-src 'self' 'unsafe-inline'; font-src 'self' data:; connect-src 'self'; object-src 'none'; base-uri 'self'; form-action 'self'; frame-ancestors 'self'" }
    ]}
  ]}
```

**Why each header**

| Header | Value | What it stops |
|---|---|---|
| `Strict-Transport-Security` | `max-age=63072000; includeSubDomains; preload` | SSL-strip / downgrade attacks and cookie theft on first visit. 2 years satisfies the HSTS-preload list minimum (1 year). **Only enable `preload` once you are certain every subdomain is HTTPS-only** — removal takes months. |
| `X-Frame-Options` | `SAMEORIGIN` | clickjacking. `DENY` also works; `SAMEORIGIN` is chosen so the site can never be framed by an attacker while still allowing the owner to embed their own page. |
| `X-Content-Type-Options` | `nosniff` | MIME-confusion attacks — stops the browser executing a mislabelled file as script. |
| `Referrer-Policy` | `strict-origin-when-cross-origin` | leaks only the origin to third parties; keeps full paths private. |
| `Permissions-Policy` | all `()` | the site needs no camera/mic/location/payment/USB. Denying them is free hardening. |
| `Cross-Origin-Opener-Policy` | `same-origin` | severs `window.opener` links from cross-origin popups (the WhatsApp hand-off is a plain link, so nothing breaks). |

`cleanUrls` makes `/index.html` redirect to `/`, so the canonical URL has exactly one form.

## 5. The 404 page (technical SEO notes)

- `dist/404.html`, generated from `_src/404-body.html`, same design tokens as the homepage.
- `<meta name="robots" content="noindex,follow">` + `X-Robots-Tag: noindex` header → the soft-404
  is never indexed, but link equity still flows through `follow`.
- It returns the **real HTTP 404 status** on all three hosts (Vercel: automatic for
  `404.html`; Netlify: automatic; Cloudflare Pages: automatic). Never ship a "200 OK 404".
- Links back to `/`, `/#batches`, `/#teacher`, `/#faq` and the WhatsApp deep link so a lost
  visitor still converts.
